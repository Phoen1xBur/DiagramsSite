# Правила разработки фронтенда

## ⚠️ ВАЖНО: Запрет на использование alert(), confirm() и prompt()

**НЕ ИСПОЛЬЗУЙТЕ** встроенные функции браузера `alert()`, `confirm()` и `prompt()` в коде!

### Почему это запрещено:
- Плохой UX: блокируют интерфейс и выглядят несовременно
- Нет контроля над стилизацией
- Не соответствуют современным стандартам веб-разработки
- Плохо работают на мобильных устройствах

### Что использовать вместо:

#### Для уведомлений (замена alert):
Используйте систему Toast через `NotificationContext`:

```jsx
import { useNotification } from '../contexts/NotificationContext'

function MyComponent() {
  const { showNotification } = useNotification()
  
  // Успешное уведомление
  showNotification('Операция выполнена успешно!', 'success')
  
  // Ошибка
  showNotification('Произошла ошибка', 'error')
  
  // Предупреждение
  showNotification('Внимание!', 'warning')
  
  // Информация
  showNotification('Информация', 'info')
}
```

#### Для подтверждений (замена confirm):
Создайте модальное окно подтверждения или используйте библиотеку для диалогов.

#### Для ввода данных (замена prompt):
Создайте модальное окно с формой или используйте библиотеку для диалогов.

### Типы уведомлений:
- `'success'` - успешная операция (зеленый)
- `'error'` - ошибка (красный)
- `'warning'` - предупреждение (оранжевый)
- `'info'` - информация (синий)

### Примеры замены:

❌ **НЕПРАВИЛЬНО:**
```jsx
alert('Файл сохранен!')
alert('Ошибка: ' + error.message)
```

✅ **ПРАВИЛЬНО:**
```jsx
showNotification('Файл сохранен!', 'success')
showNotification('Ошибка: ' + error.message, 'error')
```

---

**Помните:** Все уведомления должны быть красивыми, ненавязчивыми и соответствовать дизайну приложения!
