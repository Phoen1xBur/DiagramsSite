## Задача 4: Добавление опции "Надпись по окружности" для длинных текстов в диаграмме
**Проблема:** Когда текст слишком длинный, его невозможно прочитать на диаграмме. Нужны переносы строк, больший шрифт и центрирование.

**Решение:** 
- Добавлена новая опция "Надпись по окружности" во вкладке "Диаграмма" с чекбоксом и подсказкой
- В `chart_service.py` добавлен параметр `text_along_circumference`
- При включении опции используется `insidetextorientation='tangential'` с увеличенным размером шрифта (16px вместо 11px)
- Добавлена функция `wrap_text` для автоматического разбиения длинных текстов на строки (максимум 15 символов на строку) с использованием `<br>` для переносов
- Текст отображается черным цветом для лучшей читаемости
- Добавлено поле в модель БД, схемы, API endpoints и миграция `008_add_text_along_circumference.py`
- Настройка сохраняется в localStorage и загружается при открытии сохраненной диаграммы
